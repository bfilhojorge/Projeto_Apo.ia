Calculamos a potência: f(4) = 2(16) - 12 + 1.\n5. Multiplicamos: f(4) = 32 - 12 + 1.\n6. Finalizamos: f(4) = 21.\n\nRESULTADO FINAL: 21;\nSEGUNDA ABORDAGEM - CÁLCULO DAS RAÍZES:\n\nVamos utilizar a mesma função quadrática, mas agora encontrar suas raízes utilizando Bhaskara.\n\nCalcular_raizes(a, b, c):\n    delta = b**2 - 4*a*c\n    x1 = (-b + delta**0.5) / (2*a)\n    x2 = (-b - delta**0.5) / (2*a)\n  x1, x2\n\ncalcular raizes(2, -3, 1)\n\n\nRESOLUÇÃO PASSO A PASSO:\n\n1. Identificamos os coeficientes: a = 2, b = -3 e c = 1.\n2. Calculamos o delta: Δ = b² - 4ac.\n3. Substituímos: Δ = (-3)² - 4(2)(1).\n4. Resolvemos: Δ = 9 - 8 = 1.\n5. Aplicamos Bhaskara: x = (-b ± √Δ) / 2a.\n6. Primeira raiz: x1 = (3 + 1) / 4 = 1.\n7. Segunda raiz: x2 = (3 - 1) / 4 = 0,5.\n\nRESULTADO FINAL: As raízes são 1 e 0,5.
